# P03-Analisis-Predictivo-de-la-Calidad-del-Vino-Tinto

Este proyecto desarrolla modelos de Machine Learning para predecir la calidad del vino tinto a partir de variables fisicoquímicas. Se utilizaron modelos de ensamble como Random Forest y XGBoost, incorporando optimización de hiperparámetros, validación cruzada y pipelines de preprocesamiento para comparar el desempeño de los modelos.

El dataset fue obtenido de Kaggle y contiene información relacionada con propiedades químicas del vino, como acidez, pH, alcohol y sulfatos. El objetivo principal es identificar qué modelo ofrece mejores resultados en la clasificación de la calidad del vino.
